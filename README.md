# 旧书角 · 二手书挂牌审核台

`books.csv` 固定 25 条（不增删改），输出 `listings.csv` 25 行；单文件离线网页。

## 1. 功能与运行
双击 `index.html`（Chrome/Edge）即可，无需服务器/联网/CDN/API。页面内嵌 25 条只读数据，也可上传 `books.csv` 复算；支持全部/可自动/待人工/重复筛选、排序、点行查看原话/ISBN/依据并修改版本、价格、决策、理由；导出与表格当前值一致（25 行，按原始 id）。对象视图仅查看合并结果，不改变导出。

## 2. 审核规则与 auto/manual
- 版本：只取明确“第 N 版”、上下册、年月版；含“应该是/看图/不确定/书名可能不对”→unknown；印刷年不算版次，不猜。
- ISBN：缺失留空记 `missing_isbn`；13 位校验失败记 `isbn_invalid`；通过但无外部核验记 `bib_unverified`。不补造、不替换、不纠正。
- 品相：全新→A；九成新无笔记→A，有笔记/划线→B；八成→B；七成/六成→C；无法识别→unknown；缺页/缺答案册→`incomplete`。
- auto 闸门：版本、品相非 unknown；ISBN 有值且校验通过；无 `missing_isbn`、`isbn_invalid`、`price_anomaly`、`incomplete`、任何重复标记、`title_uncertain`、`type_uncertain`。`bib_unverified` 不单独阻断。
- 程序逐条计算：**auto 8**（b03、b06、b07、b10、b14、b15、b18、b19），**manual 17**；非预先指定。

## 3. ABC 定价系数
以卖家标价为锚，按品相取整：**A 0.90–1.10、B 0.85–1.05、C 0.75–1.00**。正常记录用标价×系数；异常记录有同书名、同品相的非异常同组记录时，用其中位标价作锚，否则区间留空。建议价不是市场定价。

## 4. b12、b23 的价格异常依据
程序先排除固定的 b12、b23，再对其余 **23 条**标价动态求最小/最大值，得 **6–60 元**。b12 的 1 元低于下限，b23 的 999 元高于上限，均记 `price_anomaly`；二者无同书名、同品相的非异常同组记录可作锚，故建议价留空。该范围仅来自本批 23 条，是本批内部异常线，**不是市场定价标准**，不可外推。

## 5. 重复与独立挂牌对象
- **确认 5 组**：b01/b02、b08/b09、b12/b13、b16/b17、b24/b25（规范化书名+版本相同）。对象视图各合为 1 个（G01–G05），导出仍 25 行；b16/b17 品相 A/C 且 b17 缺 ISBN，G04 以 b16 为展示代表，成员详情保留差异。
- **待核实 2 组**：b04/b05（b05 版本 unknown，弱重复）、b21/b22（“实验书”书种存疑）。不合并、不删除，4 条各自成对象并转人工。
- **单条 11 条**：b03、b06、b07、b10、b11、b14、b15、b18、b19、b20、b23。对象数 = 5 + 4 + 11 = **20**；页面核对为 25 条原始、5 组、2 组候选、20 个对象。

## 6. AI 使用、验证与责任边界
AI 用于理解卖家备注、提出候选规则、编写代码和 README；不调用 Open Library 等外部书目 API，不自动补齐、修改或猜测 ISBN。最终审核决策、价格区间和异常识别由明确程序规则执行，AI 判断不直接作为业务结论。验证：对照题面、检查原始数据、手算 ISBN-13、实跑页面核对统计和 25 行、页面导出与 `listings.csv` 逐字比对（本次一致，26 行含表头）、检查 8 条 auto、核对重复组/对象数并查代码历史。

## 7. AI 输出有误、经人工修正的案例
- **案例一（自动闸门过严）**：初始规则把 `bib_unverified` 放入阻断列表，而所有 ISBN 校验通过的候选都带此标记，故 **auto=0、manual=25**。人工对照题面，确认题目未要求外部书目核验，且不应调用 Open Library 等外部 API 自动补齐/猜测 ISBN；修正为 `bib_unverified` 不单独阻断，缺失 ISBN、校验失败及其他实质风险仍阻断。修正后 **auto=8、manual=17**，页面统计与 CSV 一致。可核对：Cursor 提交检查点 `aeeb7d07…`（2026-10-27 23:04）保留含 `bib_unverified` 的旧 `blocking` 片段，当前 `index.html` 已无此条件。
- **案例二（重复关联≠挂牌合并）**：b16/b17 同书名同版，但 b16 为 A、ISBN 有效、11 元，b17 为 C、缺 ISBN、7 元。程序按“书名+版本”确认重复关联并生成 G04 合并展示（以 b16 为代表，成员详情保留 b17 差异）；原始 25 行未丢失，G04 仍为 manual，不能自动挂牌；最终合并或分别挂牌、如何定价由人工决定。核对：5 个确认组、2 个候选组、20 个对象，导出 25 行。

## 8. 局限与仍需人工审核
ISBN 仅本地格式/校验位，`bib_unverified` 不等于书目核验，不能确认印次/版次/课程配套；品相仅凭文字，无照片/实物；价格仅本批 23 条小样本且 b12、b23 固定排除，不是市场价；弱重复/书种疑点不自动合并。需人工：全部 17 条 manual，尤其 5 组重复的取舍/定价（含 b16/b17）、b04/b05 与 b21/b22 是否同书、b12/b23 异常价、b24 ISBN 校验失败、b25 缺答案册、b11/b20 版本 unknown。详情面板仍有一句“书目未核验默认 manual”旧文案，与实际闸门不一致，以代码/表格为准。页面修改仅当前会话有效，刷新恢复内嵌数据，正式使用前须导出保存。
